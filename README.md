# 🍳 Recipe AI Assistant

Aplikasi web modern berbasis **Next.js (App Router)** dan **Tailwind CSS** yang memanfaatkan **Groq API** (Llama model) untuk membantu pengguna menghasilkan resep masakan secara instan berdasarkan bahan-bahan yang tersedia di dapur.

---

## ✨ Fitur Utama

- **AI-Powered Recipes**: Menghasilkan 2 pilihan resep cerdas beserta estimasi waktu memasak.
- **Langkah-Langkah Detail**: Panduan memasak yang jelas dan mendetail untuk pemula.
- **Kategori Masakan**: Filter kategori mulai dari *Berkuah*, *Goreng/Tumis*, *Sehat/Diet*, hingga *Cepat Saji*.
- **Copy to Clipboard**: Fitur sekali klik untuk menyalin resep agar mudah dibagikan (misal ke WhatsApp).
- **Responsive UI/UX**: Tampilan modern, bersih, dan ramah pengguna untuk perangkat mobile maupun desktop.

---

## 🛠️ Tech Stack

- **Frontend & Backend**: Next.js (App Router), React, TypeScript
- **Styling**: Tailwind CSS
- **AI Engine**: Groq SDK (`openai/gpt-oss-120b`)
- **Deployment**: Vercel
